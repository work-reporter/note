从成田 T1 到新井药师前｜25步完整攻略

出从靠近4号、5号出口一侧的“JR／西武方向闸机”刷出后左转

通往地面的蓝框电梯
第二部电梯内：显示“1”，上到地面一层1F

不要进JR闸机，也不要走2号或3号出口的楼梯。只找电梯图标和“电梯专用出口”。

21

到地面后走平路，过站前广场去 BIGBOX

这段不是室内直连，而且BIGBOX不在电梯门正前方。
出地面电梯 → 立即左转 → 过眼前通向车站高架桥的短横道 → 过街后再次左转 → 沿广场平路直走去BIGBOX → 从交番（派出所）旁的西武BIGBOX入口进入（牌上日文：ビッグボックス口）。

如果电梯开门时正前方看不到BIGBOX，不是走错；要先左转过短横道，过街后再左转，才会看到BIGBOX大楼。全程是短距离室外平路，没有楼梯；过街先看信号与车辆，行李箱慢慢拉。

出电梯左转→过短横道→再次左转→BIGBOX
出地面电梯后左转：先过前方这段短横道
过横道后再左转：认准左前方的BIGBOX大楼
22

从BIGBOX入口刷进西武新宿线，电梯按“2”

西武新宿线主要认“西武新宿线”；蓝绿色标志和SS02只是现场辅助图形。

在BIGBOX入口（牌上日文：ビッグボックス口）用同一张交通卡刷进西武新宿线。入口闸机在地面一层1F；刷卡后找电梯，进去按数字2，到地面二层2F站台层。电梯开门后找头顶电子显示牌左上角的蓝底大数字3；3是站台号，不是楼层。数字5去西武新宿，是反方向。

2进电梯后按数字2 → 地面二层2F
3开门到站台层后，看头顶电子显示牌的蓝底数字3 → 3号线

按2到地面二层2F：电梯开门后进入3、4号线共用站台
23

只乘电子屏显示“各停”的列车，快车不要上

乘坐站台电子屏显示“各停”的列车，并在脚下写着“各駅停車”的地面标志附近等候。“各停”和“各駅停車”翻译成中文，都是“各站停车／慢车”的意思。脚下文字只表示候车位置，最终仍以这一班车的电子屏显示“各停”为准。急行、准急等快车会越过新井药师前；就算更早发车也不要上。

上车前只核对两项

  • 西武新宿线3号线
  • 电子屏显示“各停”

站台方向牌可能写“所泽／本川越／拝岛方向”，但列车终点也可能是上石神井、田无、新所泽或玉川上水；不要拿终点名称当成必须条件。

左上角蓝底3＝3号线；列车种类只认“各停”两个字
完整站台场景：地面靠近镜头处有多组“各駅停車”
地面黑底白字“各駅停車”＝各站停车／慢车候车位置

照片：MaedaAkihiko / Wikimedia Commons / CC BY-SA 4.0；第一张保留完整构图，第二张裁切放大地面“各駅停車”标识。

为了到新井药师前南口，平路走得动的话可在高田马场站台往列车前方走，尽量乘最前面的8号车厢；不想多走就在电梯附近上车，到站后再沿站台平走。
24

乘西武新宿线各站停车慢车，坐3站到新井药师前

从高田马场出发后依次是：下落合 → 中井 → 新井药师前（站牌写：新井薬師前），通常约6～7分钟。不要只靠听日语；看屏幕或站牌上的“新井薬師前”站名，并提前设手机提醒。

高田马场→下落合→中井→新井药师前
第四段｜到达

25

到新井药师前直接下车，顺着人流前往“南口”

到新井药师前后直接下车，顺着人流方向走，并以南口箭头为准；到闸机后刷卡出站。

如果当天出口是南翼怎么办？

北翼（MF815按此准备）向航站楼中央方向走，约等于在大厅向左走 → 找中央口C1和旅客服务中心背后的电梯 → 按B1到地下一层B1。
南翼（临时调整时）同样向航站楼中央方向走，约等于在大厅向右走 → 找同一组中央大楼电梯 → 按B1到地下一层B1。

两边的共同目标都是中央大楼电梯。到地下一层B1后才跟小火车图标走平路去京成线；不要乘大厅里最近的扶梯下楼。
